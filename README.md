# 生活仪式感待办 · Life Ritual Todo

> 一个帮你把"每天该做的事"变成仪式感的微信小程序：添加任务、勾选完成、周回顾、连续打卡，让坚持看得见。

## 项目简介

`life-ritual-todo` 是一款**纯前端**的微信小程序，用于管理每日 / 每周任务。所有数据保存在**本地**（手机本地存储），不依赖任何服务器，安装即用、离线可用、隐私可控。

适合作为个人效率工具，也适合作为**原生微信小程序开发的练手 / 作品集项目**。

## 技术栈

- **原生微信小程序**：WXML（结构）+ WXSS（样式）+ JavaScript（逻辑），无第三方框架
- **本地存储**：`wx.setStorage` / `wx.getStorage`，数据持久化在用户手机，**无后端、无网络请求**
- **组件化**：7 个可复用自定义组件
- **Canvas**：周回顾分享卡片绘制

## 功能列表

- ✅ 任务增 / 删 / 改，支持 Emoji 图标与手动输入图标
- ✅ 多分区（分类）管理，自定义分区与配色
- ✅ 任务备注（可选填）
- ✅ 时间设置：无时间 / 开始-结束 / 截止时间
- ✅ 今日任务列表、勾选完成、进度环可视化
- ✅ 周回顾统计、连续打卡天数、生成分享卡片
- ✅ 每日语录

│   ├── review-modal/                 # 完成复盘弹窗

│   ├── progress-ring/                # 进度环

## 运行方式

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择「导入项目」，目录指向本仓库根目录
3. AppID 填你自己的小程序 AppID（或选择「测试号」快速预览）
4. 编译即可在模拟器 / 真机预览

> 本项目数据保存在本地，首次运行即为空状态，可自由添加任务体验。
